# 🤖 AI Resume Analyser
 
An AI-powered resume analyser that matches resumes to job listings, provides ATS scores, and gives personalised feedback — all running in the browser with no backend required.

## ✨ What It Does
 
- Upload and store resumes in one place
- Paste any job description and get an **ATS match score**
- Receive **AI-generated feedback** tailored to that specific job listing
- Authenticate users entirely in the browser — no server needed
- Works across all devices with a fully responsive UI
---
 
## 🛠️ Tech Stack
 
| Technology | Purpose |
|---|---|
| React.js | UI components and routing |
| TypeScript | Type-safe code |
| React Router v7 | Page navigation and routing |
| Puter.js | Serverless auth, storage, and AI — no backend |
| Tailwind CSS | Styling and responsive layout |
| Zustand | Global state management |
| Vite | Build tool and dev server |

## 🚀 Run Locally
 
```bash
# 1. Clone the repository
git clone https://github.com/mearning7905-debug/AI-Resume-Analyser.git
 
# 2. Go into the project folder
cd AI-Resume-Analyser
 
# 3. Install dependencies
npm install
 
# 4. Start the development server
npm run dev
```
 
Open `http://localhost:5173` in your browser.
 
---
 
## 📦 Build for Production
 
```bash
npm run build
```
